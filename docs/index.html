Method in brief

Trial records are pulled from the ClinicalTrials.gov API and refreshed incrementally. Each trial is assigned to a mechanism class by a language model using a fixed taxonomy; uncertain calls are flagged for manual review. A separate curator step watches unclassified trials for emerging mechanisms and proposes new classes, which are only added after human review.

Manual spot-checks of classifications against Alzforum Therapeutics are logged on the Data quality page. ClinicalTrials.gov is not exhaustive for non-US studies.
